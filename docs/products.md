# Модуль 2. Управление товарами

## 1. Основные функции

### 1.1. Создание товара

Простой товар или товар с вариациями. Поля:

- [ ] название (RO/RU)
- [ ] URL (RO/RU)
- [ ] краткое и полное описание (RO/RU)
- [ ] основная и дополнительные категории
- [ ] характеристики товара
- [ ] единица продажи
- [ ] изображения
- [ ] SEO Title и Meta Description (RO/RU)
- [ ] статус товара

- Простой товар: цена и остаток — на уровне товара.
- Товар с вариациями: цена и остаток — отдельно на каждую вариацию; на уровне основного товара цена/остаток не используются.
- Внутренний ID создаётся автоматически для товара и каждой вариации; SKU — отдельное необязательное поле.

### 1.2. Обязательные поля для публикации

Незавершённый товар можно сохранить как черновик, но не опубликовать. Для публикации нужны:

- название RO и RU;
- краткое описание RO и RU;
- основная категория;
- единица продажи;
- основное изображение;
- простой товар — цена и остаток;
- товар с вариациями — минимум одна полностью заполненная **активная** вариация.

Все активные вариации обязаны иметь заполненные обязательные поля; незавершённую вариацию можно сохранить только в отключённом состоянии.

### 1.3. Редактирование товара

После создания редактируется всё (тексты, категории, характеристики, единица продажи, цены, остатки, изображения, вариации, SEO, статус). Для URL/скидок/остатков/бейджа «Новинка» — особые правила (см. ниже).

### 1.4. Статусы товара

- **Черновик** — сохранён, не опубликован.
- **Опубликован** — виден на сайте.
- **Скрыт** — временно скрыт без удаления.

Переключение «Опубликован» ↔ «Скрыт» доступно прямо из списка товаров.

### 1.5. Список, поиск и фильтрация

В общем списке товаров:

- изображение, название, внутренний ID, SKU (если есть), основная категория;
- цена или диапазон цен;
- остаток/статус наличия;
- статус публикации;
- активная скидка;
- бейдж «Новинка».

Действия из списка: редактировать, быстро показать/скрыть, создать копию, переместить в корзину.

**Поиск** по: названию (RO/RU), внутреннему ID товара, внутреннему ID вариации, SKU товара, SKU вариации.
- Поиск по ID/SKU вариации → показывает основной товар + указание вариации.
- Название/SKU — частичное совпадение; внутренний ID — точное совпадение.

**Фильтрация** по: категории, статусу публикации, наличию, активной скидке, бейджу «Новинка».

## 2. Название товара

- Уникальность в пределах языковой версии (RO среди RO, RU среди RU); при совпадении — блокирующая ошибка.
- Товары с одинаковым базовым названием от разных производителей — разные названия, например:
  - «Ароматизатор Mango — Iberchem»
  - «Ароматизатор Mango — French Color & Fragrance»
- Вариации одного товара **не** считаются отдельными товарами с одинаковым названием.

## 3. ID товара, ID вариации и SKU

### 3.1. Внутренний ID

- Автогенерируется для товара и каждой вариации; не редактируется; не меняется при изменении названия/категории/характеристик/цены/URL.
- ID товара и ID вариации видны в админке.
- При копировании товара — новые ID для копии и всех её вариаций.

### 3.2. SKU

- Отдельное необязательное поле для товара и для каждой вариации.
- Не генерируется автоматически, вводится вручную; можно добавить/изменить позже.
- Уникальность проверяется, если поле заполнено — дубликат блокирует сохранение.
- При копировании товара SKU **не** копируется. При переносе со старого сайта существующие SKU сохраняются.

## 4. Категории и производители

- Товар может быть в нескольких категориях; одна — основная, остальные — дополнительные.

## 5. Описание товара

- Краткое и полное описание (RO/RU); полное — под основным блоком товара.
- WYSIWYG-редактор, вставка из Word/Google Docs без ручной правки HTML.
- При вставке сохраняются: абзацы/переносы, заголовки H2–H3, списки, bold/italic, встроенные ссылки, **таблицы**.
- Автоочистка служебного кода/стилей Word; шрифты/размеры/цвета из Word не переопределяют дизайн сайта.

## 6. URL товара

- Автогенерация slugify (RO/RU отдельно), правила транслитерации те же, что для категорий (см. [`categories.md#3-формирование-url`](./categories.md#3-формирование-url)).
- Уникальность проверяется по текущим и старым (редиректным) URL; конфликт — блокирующая ошибка.
- Смена названия опубликованного товара не меняет URL автоматически; ручное изменение → редирект 301 со старого на новый.
- Все старые URL редиректят напрямую на текущий (без цепочек); циклы запрещены.

## 7. Характеристики и вариации

### 7.1. Справочник характеристик

- Администратор создаёт характеристики и их значения по мере необходимости — список не хардкодится.
- Для каждой характеристики: название RO/RU; добавление/редактирование/отключение значений; порядок значений; флаги «только информация о товаре» / «используется для вариаций» / «доступна для будущих фильтров».
- Характеристики/значения, уже используемые в товарах/заказах, нельзя удалить окончательно — только отключить.
- Примеры: объём, вес, цвет, размер, тип воска.

### 7.2. Создание вариаций

- Товар с вариациями может комбинировать несколько характеристик одновременно (например «Цвет + Размер»); каждая комбинация значений = отдельная вариация.
- Поля вариации:
  - автоматический внутренний ID;
  - значения характеристик;
  - необязательный SKU;
  - обычная цена;
  - параметры акции (см. §10);
  - остаток;
  - необязательное изображение;
  - статус активности.
- При выборе вариации на витрине обновляются изображение, цена, наличие; без собственного изображения — используется основное изображение товара.

### 7.3. Выбор вариации и canonical URL

- Вариации не имеют собственных индексируемых страниц/человекочитаемых URL.
- Выбранная вариация может передаваться параметром URL/внутренним идентификатором → открывает основную страницу товара с автовыбором вариации.
- Основной URL товара — self-referencing canonical.
- URL с параметром вариации → canonical всегда указывает на основной URL без параметров.
- Ссылки с параметрами вариаций **не** попадают в sitemap и не получают отдельные SEO Title/Meta Description.

### 7.4. Активность и наличие вариации

- Вариацию можно отключить отдельно, не скрывая весь товар.
- Остаток = 0 → «Нет в наличии», но видима.
- Отключена администратором → выведена из продажи, не показывается покупателю.
- Вариацию с нулевым остатком можно выбрать для просмотра (изображение/цена/характеристики); кнопка «в корзину» заблокирована.

## 8. Единицы продажи

- Отдельный справочник единиц продажи (RO/RU название), редактируемый/сортируемый/отключаемый администратором; не хардкодится.
- Единица, используемая в товарах/заказах, окончательно не удаляется — только отключается.
- Единица продажи ≠ характеристика упаковки:

| Товар | Единица продажи | Характеристика |
|---|---|---|
| Ароматизатор 30 мл (поштучно) | флакон / штука | Объём = 30 мл |
| Краситель 10 г (упаковками) | упаковка / штука | Вес = 10 г |
| Фитиль | метр | — |

- Остаток учитывается в единицах продажи, не в единицах характеристики.

### 8.1. Ароматизаторы и красители

- Объём/вес — значения вариаций; после выбора вариации покупатель указывает количество флаконов/упаковок.
- Цена и остаток — отдельно по каждой вариации; SKU — вручную при необходимости.

### 8.2. Фитиль на метраж

- Единица продажи = 1 метр; покупатель выбирает только целое количество метров (дробные — 0.5, 1.5 — запрещены).
- Цена и остаток — в метрах.

## 9. Управление остатками

- Простой товар — остаток на уровне товара; с вариациями — отдельно на каждую вариацию.
- Статус наличия рассчитывается автоматически:
  - остаток > 0 → RO `În stoc`, RU «В наличии»;
  - остаток = 0 → RO `Stoc epuizat`, RU «Нет в наличии».
- Статус наличия не редактируется вручную отдельно от остатка; точное количество покупателю не показывается.
- При нулевом остатке товар виден, но не добавляется в корзину/заказ; предзаказ не предусмотрен.

### 9.1. Проверка и резервирование

- Наличие/количество перепроверяется перед созданием заказа; при нехватке — заказ нельзя оформить до правки корзины (для вариации — с указанием конкретного варианта в сообщении об ошибке).
- Добавление в корзину / открытие checkout **не** резервирует товар.
- Технический механизм резервирования и момент списания остатка — на усмотрение разработчика.
- Два покупателя не должны одновременно получить последнюю единицу товара (защита от overselling); для онлайн-оплаты желателен временный резерв до подтверждения/отклонения платежа.

## 10. Цена и скидка

- Простой товар: обычная цена, акционная цена, дата/время начала и окончания акции.
- Товар с вариациями: акция применяется ко всем активным вариациям по правилам §10.1.
- Период акции — часовой пояс **Europe/Chisinau**; дата окончания не может быть раньше даты начала.
- Во время акции: обычная цена зачёркнута, рядом — акционная цена и авторассчитанный % скидки. После окончания — возврат к обычной цене, бейдж скидки скрыт.
- Акционную цену можно задать без срока действия — тогда действует до ручного отключения.
- Акционная цена обязана быть ниже обычной, иначе — блокирующая ошибка.

### 10.1. Цена и скидка товара с вариациями

- До выбора вариации — диапазон цен активных вариаций (например 30–260 lei); после выбора — конкретная цена.
- Акция применяется ко **всем** активным вариациям сразу: общий % скидки + период (или бессрочно до отключения). Акционная цена каждой вариации = её обычная цена × общий %.
- Во время акции: обычный диапазон зачёркнут, рядом — диапазон акционных цен; после выбора вариации — её зачёркнутая обычная цена, рассчитанная акционная цена, общий %.
- Разные % скидки на разные вариации одного товара — **не требуется**.

## 11. Бейдж «Новинка»

- RO — `NOU`; RU — «НОВИНКА».
- По умолчанию — 14 дней с момента первой публикации.
- Дату окончания можно изменить вручную; бейдж можно отключить вручную.
- Редактирование, изменение цены, пополнение остатка — **не** сбрасывают таймер.
- Для товаров, перенесённых со старого сайта, бейдж автоматически **не** включается.

## 12. Изображения

- Основное изображение.
- Галерея дополнительных изображений.
- Порядок — drag & drop.
- Удаление и замена.
- Необязательное изображение для каждой вариации (fallback — основное изображение товара).
- ALT — вручную, отдельно RO/RU; если не заполнен — атрибут пустой (без автоподстановки названия товара для всех картинок).

> **Вопрос для согласования:** рекомендуемые размеры, пропорции, форматы и максимальный размер загружаемого файла — нужно от заказчика.

## 13. SEO-данные

- SEO Title и Meta Description — RO/RU, только на уровне основного товара.
- При сохранении SEO Title — проверка совпадений с другими страницами той же языковой версии; при совпадении — предупреждение, но **не** блокирует сохранение.
- Для вариаций отдельные SEO-поля не создаются (см. §7.3 про canonical).

## 14. Создание копии товара

Переносится: тексты, категории, характеристики, структура вариаций, изображения, цены, SEO-данные.

Копия создаётся как черновик с временным отличающимся названием; перед публикацией требуется новое уникальное название.

**Не переносится:**

- SKU товара и вариаций (остаются пустыми);
- URL основного товара и вариаций (формируются заново после смены названия/значений);
- остатки;
- дата первой публикации;
- автоматический бейдж «Новинка»;
- история редиректов.

Для копии товара и всех вариаций — новые внутренние ID.

## 15. Удаление и восстановление

- Удаление → сначала корзина (не показывается на сайте) → восстановление или финальное удаление вручную.
- Товар в оформленных заказах: удаление **не** меняет название/цену/вариацию и прочие данные, сохранённые в истории заказа (снапшот на момент покупки).
- Финальное удаление опубликованного товара: администратор указывает страницу для редиректа 301; без подходящей — статус 410 (без авторедиректа на главную).
- Выбранное правило (редирект/410) применяется и к текущему URL товара, и ко всем ранее сохранённым URL.
